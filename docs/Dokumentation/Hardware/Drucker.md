# Drucker

## Laserdrucker

Der Netzwerkdrucker wird für die Alarmdepesche und generell für Ausdrucke verwendet.

Modell: HP LaserJet Pro 3002dw  
Anschaffung: 2026  
Angeschlossen an: [Repeater](../Hardware/Netzwerk.md#repeater)

## Etikettendrucker

Für das Drucken von Labels für die Geräteverwaltung wird ein Etikettendrucker verwendet.

Modell: Zebra ZD220  
Anschaffung: 2023  
Angeschlossen an: [RaspberryPi Etikettendrucker](RaspberryPi.md#etikettendrucker)

## Multifunktionsgerät

Modell: Brother MFC-7320  
Anschaffung: 2024 (ausgemustert von UG-ÖEL)
